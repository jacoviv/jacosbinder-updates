jacosbinder 3.4.0

Released 2026-11-20 · release page · all versions

  • Deckbuilder: a third label, ARC (archived), next to WIP and ACT – only a label, the deck stays in the list
  • Cubes have the labels too: WIP, ACT and ARC, with the filter and the switch in the editor
  • In each format, and in the cube list: ACT first, then WIP, then ARC, each A–Z by name

Windows

jacosbinder-3.4.0-setup.exe – installed copies update themselves from then on (Data → Program → Install update). Portable: jacosbinder-3.4.0-portable.zip, unzip over the old folder.

Linux (Flatpak)

Install once from the updates repository; from then on new versions come through Software or flatpak update:

flatpak install --user https://jacoviv.github.io/jacosbinder-updates/jacosbinder.flatpakref

Installed earlier from a .flatpak file? Remove that copy first (your data folder and settings stay), then install as above:

flatpak uninstall --user io.github.jacoviv.jacosbinder
flatpak install --user https://jacoviv.github.io/jacosbinder-updates/jacosbinder.flatpakref

Without Flatpak: jacosbinder-3.4.0-linux-amd64 (no automatic updates).
